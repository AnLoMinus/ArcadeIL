## חזון
ArcadeIL הוא מאגר דגימות ותבניות ליישומים ופרויקטים קלים לשיתוף ולתרגול. המטרה היא לשמור על בסיס נקי, ברור ונוח לשימוש מהיר.

## שימוש מהיר
1. שכפול המאגר:
   ```bash
   git clone https://github.com/AnLoMinus/ArcadeIL.git
   cd ArcadeIL
   ```
2. פתיחת הקובץ הראשי בדפדפן:
   ```bash
   open index.html
   ```

## תיעוד מקוצר
- `index.html` — נקודת כניסה בסיסית לדוגמה.
- `README.md` — דף הבית והתיעוד הראשוני.
- `CHANGELOG.md` — היסטוריית גרסאות.
